Test string: 10 — expected Accept, actual Reject before fix, Accept after fix.
This string is the simplest nontrivial example that should be accepted and so exposes 
a fundamental implementation error if it fails. The bug I had was missing the nondeterministic branching on input 1 
from the start state: q0 must both continue scanning and simultaneously guess that the current 1 is the second-to-last. 
The fix was to add two transitions labeled 1 from q0 — one back to q0 and one to q1 — then q1 consumes exactly one more 
symbol to reach the accepting state q2, which has no outgoing transitions.
